# FitnessApp v0.1-beta

Eine hochmoderne iOS Fitness-Zentrale mit HealthKit-Integration, entwickelt im **Liquid Glass Design** (iOS 26 Standard).

## 🚀 Features

- **Personalisiertes Dashboard:** Dynamische Begrüßung und Motivations-Engine basierend auf deinen Aktivitätsringen.
- **Apple Aktivitätsringe:** Originalgetreue Darstellung von Bewegen, Trainieren und Stehen.
- **Erweitertes Tracking:** Zusätzliche Ringe für Schritte und Hydrierung (Wasseraufnahme).
- **Interaktive Statistiken:** Detaillierte Trends für Tage, Wochen, Monate und Jahre mit Tap-to-Reveal Datenpunkten.
- **Workout Historie:** Automatische Synchronisation deiner Apple Watch Trainings mit über 40 Sportarten und spezifischen Icons.
- **Push-Benachrichtigungen:** Erhalte automatische Zusammenfassungen nach Workouts und Feierlichkeiten beim Erreichen deiner Tagesziele.
- **Privacy First:** Alle Daten werden lokal verarbeitet und nur mit deiner expliziten HealthKit-Zustimmung gelesen.

## 🛠 Architektur

- **SwiftUI:** Modernes, deklaratives UI mit Fokus auf Performance und Flüssigkeit.
- **HealthKit:** Direkte Anbindung an das Apple Health Ökosystem.
- **Combine:** Reaktive Datenströme für Echtzeit-Updates.
- **MVVM-ish Pattern:** Saubere Trennung zwischen UI-Komponenten und Daten-Managern.

## 📱 Design (iOS 26 Standard)

Die App nutzt modernste Design-Prinzipien:
- **Spatial Depth:** Nutzung von Materialien (`thinMaterial`) und dynamischen Schatten für physische Tiefe.
- **Mesh Gradients:** Lebendige, organische Hintergründe.
- **Haptics:** Taktiles Feedback für ein immersives Erlebnis.

## 🏁 Setup

1. Öffne `FitnessApp.xcodeproj` in Xcode.
2. Starte die App auf einem iPhone (iOS 17+) oder im Simulator.
3. Durchlaufe das Onboarding und gewähre die HealthKit-Berechtigungen.
4. Fertig! Deine Daten werden automatisch synchronisiert.
